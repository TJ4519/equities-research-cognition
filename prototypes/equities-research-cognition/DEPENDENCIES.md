# Dependency Decision

The Python runtime has two dependencies:

| Dependency | Pin | Purpose |
| --- | --- | --- |
| Django | 6.0.7 | Authentication, CSRF, server-rendered views, ORM and migrations |
| Psycopg binary | 3.3.4 | PostgreSQL driver for canonical product state |

NTM and Codex CLI are operator-installed host tools. NTM instantiates
persistent subscribed Codex sessions and transports exact files; it is not
redistributed. Codex performs cognition from versioned research protocols.

Native Codex telemetry is configured through its pinned command-line settings
and standard OTLP environment header. The product uses Python's standard HTTP
client for bounded Langfuse Observations API v2 readback. There is no Langfuse
SDK, OpenTelemetry Python runtime, LangChain, model API or custom telemetry
store.

Langfuse observations are non-authoritative operational evidence. PostgreSQL
owns director dispositions, exact artifact joins, review admission, analyst
authorship and learning state. A live integration claim still requires a
service-issued identity, supported readback and an exact artifact relation.
