# Research start

Use when the user begins from an event, question, source, model, note, theme, or other professional cue.

Preserve the exact request before interpreting it.

Recover only the prior perspective, artifacts, decisions, and confirmed memory likely to change the work. Retrieve references first. Load exact material after the likely episode has been identified.

Propose:

- the professional purpose;
- intended use;
- prior work that matters;
- subjects and professional objects likely affected;
- evidence needs;
- candidate methods supported by the workspace;
- useful output forms;
- unresolved questions whose answer would change the work; and
- source-rights or tool limits.

Mark every field as observed, inferred, or already confirmed. Do not present an inferred professional object, source rule, or materiality threshold as analyst-authored.

Show the proposed interpretation in ordinary language. Ask for correction only where the answer changes sources, method, artifact action, authority, or useful output.

Create the episode and confirmed commission through the local service. Do not start child work before the confirmed commission exists.

A broad analyst request may remain broad. Each child action must later receive its own sealed context and supported output contract.
