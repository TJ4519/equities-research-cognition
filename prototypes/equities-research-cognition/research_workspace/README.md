## Context boundary

A support context contains exact admitted assertion extracts and source receipts. It does not contain full source bytes. Copying the whole document would expose separately excluded assertions from the same source.

Full-document discovery needs its own explicit action, authority, and context.

The direct process adapter binds one absolute executable to an exact working directory, a minimal environment, a timeout, and a validated output population. It does not provide operating-system filesystem or network isolation.
