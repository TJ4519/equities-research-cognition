# External cognition skills

The prototype may bind two operator-installed skills into exact work orders:

- `research-frame-search-with-domain-mechanisms` helps translate a decision
  problem into constructs, proxy gaps, rival mechanisms, discriminating
  evidence routes, and bounded claims.
- `modes-of-reasoning-panel` conditionally attacks one named epistemic failure
  and emits an inspectable delta or a kill result.

Their source is not duplicated here. `lock.json` records package identities and
an exact per-file source manifest. Campaign Studio accepts only an exact locked
selection in a director-approved work order and verifies the complete installed
package before launch and dispatch. The resulting research state must record
the named failure, realized delta and kill result. Those facts establish
version and trajectory custody; they do not prove that the operator improved
the research.

These are donor cognition mechanisms, not evidence or universal ontology. A
skill earns retention only when an isolated invocation changes a material
research decision or refusal and later survives human review.
