`a15346eec03aaf036c52b10119e44025953eb538`.

`prototypes/equities-research-cognition/`, then replaces the package route,
instructions, overview, and evidence index with self-contained public versions.

architecture-review receipt are new derived documents. The package classifier
and its architecture test were amended only to recognise `ROUTE.md` as
documentation.

Excluded from publication:

- the source repository's Git history and all other directories;
- private conversations, plans, task databases, and internal receipts;
- credentials, environment files, runtime state, caches, and protected cases;
- historical evidence JSON containing service-issued run, project, trace, or
  session identifiers; and
- operator-specific filesystem paths and links.

The omission of runtime receipts reduces the public evidence surface. The
mechanical regression suite remains available for inspection and execution;
no public document should claim more than those tests and the code establish.
